# Ornamen SVG

Folder ini untuk menyimpan file SVG ornamen arabesque yang digunakan sebagai aset terpisah jika diperlukan.

Saat ini ornamen sudah di-inline dalam `index.html` (SVG `<symbol>` dan inline `<svg>`).
Pindahkan ke sini jika ukuran HTML terlalu besar atau ornamen perlu di-reuse lintas halaman.
